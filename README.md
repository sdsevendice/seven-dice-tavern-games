# Игры в таверне от Seven Dice

Независимый модуль для Foundry VTT 14 с каталогом тавернских игр для игроков и NPC под управлением мастера.

## Каталог

1. Покер на костях — интерактивный режим готов.
2. Гоблинский дротик — интерактивный режим готов.
3. Кости Балдура — интерактивный режим готов.
4. Корона и Якорь.
5. Смертельный выстрел.
6. Помощь соседу.
7. Метка безумия.
8. Звон молота.

Для всех режимов добавлены русские карточки правил. Интерактивные столы новых игр подключаются отдельно и не меняют автономный модуль `dice-parlor`.

Открытые броски показываются через Dice So Nice, если модуль активен. Это закреплено для «Костей Балдура», «Короны и Якоря», «Помощи соседу», «Метки безумия» и «Звона молота». Закрытые игры не раскрывают кубы раньше времени.

Интерфейс использует деревянный тавернский стол и фирменные материалы Seven Dice. В «Гоблинском дротике» есть мишень, подсветка попадания, анимация полёта, синтезированный свист и отдельный звук удара.

Планируемые дополнения перечислены в [бэклоге](BACKLOG.md).

## Запуск

Активируйте модуль и нажмите кнопку с кружкой на панели инструментов токенов. Через макрос каталог открывается так:

```js
game.modules.get("seven-dice-tavern-games").api.open();
```

Покер можно открыть напрямую:

```js
game.modules.get("seven-dice-tavern-games").api.openPoker();
```
