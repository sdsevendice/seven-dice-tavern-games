# Игры в таверне от Seven Dice

Модуль для Foundry VTT 14: игры для игроков и NPC под управлением мастера.

## Готовые игры

- **Покер на костях** — одновременные личные броски, выбор сохраняемых костей, ставки и сравнение комбинаций.
- **Гоблинский дротик** — мишени двух видов, анимация попаданий и подсчёт очков.
- **Кости Балдура** — наберите сумму ближе к 21, не допустив перебора.

В каталоге есть краткие правила готовых игр; будущие игры пока недоступны.

## Установка

В Foundry VTT выберите установку модуля по манифесту:

```text
https://github.com/sdsevendice/seven-dice-tavern-games/releases/latest/download/module.json
```

Активируйте модуль в мире и нажмите кнопку с кружкой на панели токенов. Мастер выбирает участников и ставку. Актёров можно перетащить в область «NPC мастера» — подтянутся имя и изображение токена.

Dice So Nice необязателен: при его наличии открытые броски получают 3D-анимацию. Звуки игр можно отключить в настройках модуля.

Для сетевой партии нужен активный мастер. Деньги учитываются только на столе, без списания с листов персонажей. Скрытые руки не показываются соперникам в интерфейсе; ведущий технически хранит результаты. Восстановление партии поддерживается при перезагрузке той же вкладки ведущего, но не гарантируется при её закрытии или смене устройства.

После обновления перезагрузите страницы всех участников. Для новых правил покера создайте новый стол.
